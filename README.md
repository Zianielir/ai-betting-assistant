# LLM/NLP-ассистент букмекерского трейдера

## О проекте

Цель проекта — разработать ассистента, который собирает футбольные новости из открытых источников, определяет информацию, важную для конкретного матча, и формирует краткую сводку для трейдера. Система будет помогать быстро находить значимые события: травмы игроков, изменения состава, дисквалификации, заявления тренеров и другие новости, которые могут быть важны при оценке матча. Отдельное внимание будет уделено источникам информации: их доступности, полноте, надёжности и скорости появления новостей. В дальнейшем планируется использовать ML и DL/NLP для анализа новостного потока, а LLM и RAG — для формирования сводок, поиска подтверждающей информации и ответов на вопросы пользователя.

## Ожидаемый результат

Работающий ассистент, который:

- собирает футбольную информацию из нескольких источников;
- связывает новости с конкретными матчами;
- определяет релевантность и тип события;
- извлекает из текста важные сущности и факты;
- учитывает качество и скорость источников;
- хранит накопленную информацию для дальнейшего поиска;
- формирует краткую сводку по матчу;
- показывает источники;
- отвечает на уточняющие вопросы пользователя.

Если останется время, возможно добавим исследование связь между моментом появления новости и последующим движением букмекерской линии.
